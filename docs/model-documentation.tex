\section{Scope}

SolarGen forecasts rooftop photovoltaic generation for a 10 kWp south-facing rooftop array in OHZ / Osterholz-Scharmbeck. The production forecast shown in the browser and in the local history app is an Open-Meteo-weighted blend of an Open-Meteo current physical forecast and a DWD stable forecast.

The browser app obtains DWD data through the Open-Meteo DWD ICON endpoint. The local history app obtains DWD data from DWD MOSMIX. Both surfaces use the same transfer structure and final production blend.

\section{Source Physical Model}

For each source \(s \in \{\mathrm{OM}, \mathrm{DWD}\}\), hourly meteorological inputs are:

\[
I_{s,h},\ C_{s,h},\ R_{s,h},\ T_{s,h},
\]

where \(I\) is global tilted irradiance in \(\mathrm{W/m^2}\), \(C\) is cloud cover, \(R\) is precipitation, and \(T\) is ambient temperature.

The source physical model computes a rooftop generation curve:

\[
G^{\mathrm{cur}}_{s,h}
=
f_{\mathrm{site}}\left(I_{s,h}, C_{s,h}, R_{s,h}, T_{s,h}\right).
\]

The daily current total for source \(s\) is:

\[
G^{\mathrm{cur}}_{s}
=
\sum_{h=0}^{23} G^{\mathrm{cur}}_{s,h}.
\]

\section{DWD Stable Transfer}

The DWD current physical model alone did not generalize well. SolarGen therefore transforms DWD through a stable daily transfer model before production blending.

First compute a DWD sunshine/rain daily model:

\[
G^{\mathrm{raw}}_{\mathrm{DWD}}
=
\max\left(0,\ 18.3545 + 2.3510 H_{\mathrm{DWD}} - 1.9219 R^{+}_{\mathrm{DWD}}\right),
\]

where \(H_{\mathrm{DWD}}\) is DWD sunshine duration in hours and \(R^{+}_{\mathrm{DWD}}\) is DWD precipitation summed only over hours with positive tilted irradiance:

\[
R^{+}_{\mathrm{DWD}}
=
\sum_{h=0}^{23}
\mathbf{1}\{I_{\mathrm{DWD},h} > 0\} R_{\mathrm{DWD},h}.
\]

The stable DWD daily forecast is:

\[
\boxed{
G^{\mathrm{stable}}_{\mathrm{DWD}}
=
0.25 G^{\mathrm{cur}}_{\mathrm{DWD}}
+ 0.75 G^{\mathrm{raw}}_{\mathrm{DWD}}
+ 4.039
}
\]

\section{Production Blend}

The production daily forecast is:

\[
\boxed{
G^{\mathrm{prod}}
=
0.73 G^{\mathrm{cur}}_{\mathrm{OM}}
+ 0.27 G^{\mathrm{stable}}_{\mathrm{DWD}}
}
\]

There is no production-bias term in the current model.

\section{Hourly Allocation}

The DWD current hourly curve is scaled to the stable DWD daily total:

\[
\widetilde{G}_{\mathrm{DWD},h}
=
G^{\mathrm{cur}}_{\mathrm{DWD},h}
\cdot
\frac{G^{\mathrm{stable}}_{\mathrm{DWD}}}
{\sum_{j=0}^{23}G^{\mathrm{cur}}_{\mathrm{DWD},j}}.
\]

The production hourly curve is:

\[
G^{\mathrm{prod}}_h
=
0.73G^{\mathrm{cur}}_{\mathrm{OM},h}
+ 0.27\widetilde{G}_{\mathrm{DWD},h}.
\]

The curve is then scaled by a small numerical factor if needed so that:

\[
\sum_{h=0}^{23}G^{\mathrm{prod}}_h = G^{\mathrm{prod}}.
\]

Any rounding adjustment is applied to the largest positive production hour so that night hours cannot become negative.

\section{Curtailment, Load, Battery, And Value}

The browser app applies the household load, battery, export, and value model to \(G^{\mathrm{prod}}_h\). For each hour:

\[
G^{\mathrm{curt}}_h = \max(0,\ G^{\mathrm{prod}}_h - F),
\]

\[
G^{\mathrm{deliv}}_h = G^{\mathrm{prod}}_h - G^{\mathrm{curt}}_h,
\]

where \(F=6\ \mathrm{kW}\) by default. Delivered PV first covers same-hour household load, then charges the battery, and remaining surplus is exported.

\section{Selection Evidence}

The production model was selected on paired Open-Meteo and DWD day-ahead forecast history with actuals through 2026-06-12.

\begin{center}
\begin{tabular}{lrrrr}
\toprule
Model & In-sample MAE & LOO MAE & Rolling MAE & Comment \\
\midrule
Equal blend & 3.918 & fixed & 5.010 & recent low bias \\
OM only & 4.147 & fixed & -- & single source \\
DWD stable only & 4.567 & fixed & -- & single source \\
Fitted weight, no bias & 3.861 & 3.945 & 5.208 & selected \\
Fitted weight plus bias & 3.844 & 4.485 & 5.419 & overfits \\
\bottomrule
\end{tabular}
\end{center}

The selected model is not the best in-sample model. It is the smallest recalibration that improves the retained sample while avoiding a bias term that degraded out-of-sample checks.

\[
\texttt{python3 -m history\_app.cli recompute-production}
\]

and run:

\[
\texttt{npm run check}

\texttt{npm test}
